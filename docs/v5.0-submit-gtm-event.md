## 2. Default org by host

The same `presets.json` is used on every branch. The default org (when there's no `?org=`) depends on the host **serving the form**: `location.hostname` inside the iframe, never the parent site.

Logic in `haasDefaultOrg()` (`forms.js`):

1. `?org=` in the URL always wins.
2. `"sandbox": true` → `sandbox_default` on every host.
3. `"sandbox": false` → `sandbox_default` if the hostname is in `sandbox_hosts`, otherwise **prod** (hardcoded HTML values).

```json
"_config": {
  "sandbox": false,
  "sandbox_default": "uat",
  "sandbox_hosts": ["jih-marketing-forms-git-staging-john-i-haas.vercel.app", "localhost", "127.0.0.1"]
}
```

| Served from | Default org |
|---|---|
| `jih-marketing-forms.vercel.app` (production) | prod |
| `jih-marketing-forms-git-staging-john-i-haas.vercel.app` (staging) | uat |
| `localhost` / `127.0.0.1` (any port) | uat |
| Any other host | prod |

- Exact hostname match: no port, no wildcards.
- Hosts that aren't listed go to prod, so a real visitor can never be sent to a sandbox. The worst case is a test landing in prod.
- `presets.json` unavailable → hardcoded HTML values (prod).
- `?debug=1` uses the same resolution for `debugEmail`.
- To add a test environment, add its hostname to `sandbox_hosts`.

## 3. Parent origin allowlist

All origins are kept, so the form can still be tested from staging and local environments after release, and other sites can embed it.

```
https://www.johnihaas.com          https://johnihaas.com
https://betatec.com                https://www.betatec.com
https://haasstage.wpengine.com     (client WordPress staging)
https://jih-marketing-forms.vercel.app                         (embed-test.html / parent.html on prod)
https://jih-marketing-forms-git-staging-john-i-haas.vercel.app (embed-test.html on staging)
http://localhost:5500  http://127.0.0.1:5500  http://127.0.0.1:5501  http://localhost:8080  http://localhost:3000
```

Embedding the form works from any site. The allowlist only controls which parent pages receive the `form_submission` message.

## 6. What the parent site needs (betatec.com)

| # | Item |
|---|---|
| 1 | Listener script (section 5 of the requirement document) on the page, loaded before the visitor can submit |
| 2 | `FORM_ORIGIN = "https://jih-marketing-forms.vercel.app"` in production (staging: `https://jih-marketing-forms-git-staging-john-i-haas.vercel.app`) |
| 3 | iframe `src` = production form URL with `?form_id=<name>` (one value per embed). `campaign` is optional |
| 4 | iframe `id="haas-marketing-form-iframe"`, or the listener's selector changed to match theirs |
| 5 | GTM: Custom Event trigger `form_submission`; Data Layer Variables `form_id`, `form_type`, `campaign`, `submission_id`; GA4 event and/or Ads conversion tag |
| 6 | Consent: tags follow the site's consent settings |
| 7 | Any new parent domain (other sites, `www`/non-`www` variants) must be added to our allowlist |

Known limitation: the event means "submitted and redirected to the thank-you page", not "record created in Salesforce".
